# LumiFlow User Manual

**New Structured Edition**

This folder contains a **clean, reorganized version** of the LumiFlow user manual. The goal is to:

- Reduce repeated explanations.
- Clarify what each Part is for.
- Give you a clear, consistent path through all LumiFlow features.

If you prefer the older, more detailed documents, they are still available in the `user_manual` folder.

---

## Manual Parts

| Part | File | Title | Best For |

| 1 | `01_Introduction_Installation.md` | Introduction & Installation | Users installing and activating LumiFlow for the first time |

## How to Use This Manual

### Recommended Reading Order

1. **Part 1 – Introduction & Installation**  
   Install LumiFlow, enable it, and verify it works in Blender.
2. **Part 2 – Getting Started Workflow**  
   Follow the Quick Start and basic workflows to light your first product or character.
3. **Part 3 – Interface & Core Features**  
   Learn what each section of the panel does and how the main systems fit together.
4. **Part 4 – Template Library**  
   Explore the available templates and when to use each one.
5. **Part 5 – Advanced Features**  
   Learn strategies for multi-camera scenes, light linking, flip operations, and selection tools.
6. **Part 6 – Reference & Support**  
   Use as a shortcut table, troubleshooting guide, and hub for community/support links.

You can also jump directly to a specific Part when needed (for example, Part 4 when choosing a template, or Part 6 when you forget a shortcut), but the order above is a good default when reading the manual from start to finish.

---

## Cross-Part Conventions

To avoid repetition and confusion:

- **Workflows live in Part 2.**  
  Other parts only reference them ("See Part 2 – Workflow 3: Multi-Camera Product Studio").

- **Panel layout and feature summaries live in Part 3.**  
  Other parts do not re-describe the full panel, only parts that are unique.

- **Template details live in Part 4.**  
  Part 2 and 3 only show a few key templates as examples.

- **Advanced strategies live in Part 5.**  
  It assumes you already read Part 2–3.

- **Shortcut tables and troubleshooting live in Part 6.**  
  Other parts may mention shortcuts in context, but always point here for the full list.
